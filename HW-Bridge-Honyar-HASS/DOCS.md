# HW-Bridge-Honyar-HASS 加载项说明

将 Home Assistant 实体连接到 HW 智慧生活，支持灯具、开关、窗帘、空调和风扇。名称与房间跟随 HA。

### **声明**

此项目灵感来源自[ha_hwhomebridge](https://github.com/Wangxiaokang666-666/ha_hwhomebridge)项目，sdk源码来自[honyar](https://github.com/ppq-ppq/honyar)，为个人实验产物，此仓库将不会更新，如有Bug请自行用AI修改。

## 安装与更新

1. 停止占用 UDP 5683 的其他桥接加载项或集成。
2. 解压对应架构的离线安装包，将整个 `HW-Bridge-Honyar-HASS` 文件夹放到 HA 的 `/addons/` 目录。
3. 刷新加载项商店，安装或更新 **HW-Bridge-Honyar-HASS**。
4. 设置 `network_interface` 为联网网卡（例如 `end0`）；留空时使用默认路由网卡。
5. 启动加载项并打开 Web UI，确认 HA 和 HW 连接状态。
6. SDK仅支持安卓APP进行配对

首次安装时，在智慧生活中添加“XX智慧主机III”网关。默认使用 `pairing_auth: sdk_default`；

离线包包含运行环境，无需下载基础镜像、apt 或 pip。源码包用于自行构建，不能与离线包的 Dockerfile 混用。

## 设备控制

| HA 类型 | 智慧生活中的映射 |
| --- | --- |
| `light` | 灯具开关，以及实体支持的亮度和色温 |
| `switch` | 1 键开关，开关状态双向同步 |
| `cover` | 3 键开关：第 1 键开、第 2 键关、第 3 键停 |
| `climate` | 空调开关、温度、制冷/制热/送风/除湿和低/中/高风速 |
| `fan` | 开关及实体支持的风速 |

窗帘三个按键是点击后复位的动作键，释放按键不会执行相反动作；按键不表示位置或运动状态。只执行 HA 实体支持的动作，缺失能力会在设备列表提示；离线实体不可控制。

空调模式和风速按 HA 实际提供的选项匹配，支持常见中英文风速名称。开关、温度等状态以 HA 实际回报为准。

## 名称与房间

名称使用 HA 实体的显示名称，缺失时使用实体 ID。房间优先使用实体所属区域，其次设备所属区域；未分配区域时使用 `Home Assistant`。

在 HA 改名或调整区域后会重新同步。智慧生活中的手动改名和房间调整不会写回 HA，之后的同步可能覆盖这些调整。名称和房间每项最多 39 个 UTF-8 字节，纯中文通常最多 13 字；超长内容自动截断。建议使用简短、可区分的名称。



源码支持 `aarch64`（使用QEMU虚拟ARM32，x86平台请自行适配）
